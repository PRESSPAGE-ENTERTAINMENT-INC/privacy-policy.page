Official privacy policy website for PressPage Entertainment Inc. and its affiliated brands.

This repository hosts the public privacy policy website available at:

https://privacy-policy.page

The site provides:

- General privacy policy information

- Accessibility-compliant access to privacy disclosures

## Accessibility

This website is designed to comply with modern accessibility standards, including:

- WCAG 2.1 AA
- Section 508
- ADA (Americans with Disabilities Act)

Accessibility features include:

- Keyboard navigation
- Screen reader compatibility
- Proper semantic HTML landmarks
- Accessible form controls
- Focus indicators
- Skip-to-content navigation
- Mobile accessibility support
- ARIA labels and dialog support

## Technology Stack

- HTML5
- CSS3
- W3.CSS
- Font Awesome
- Vanilla JavaScript

No tracking frameworks are required for core functionality.

## Privacy First

The website follows a privacy-first approach:

- Minimal data collection
- No unnecessary tracking
- Transparency regarding third-party services
- Public disclosure of data handling practices

## Development

Clone the repository:

```bash
git clone https://github.com/PRESSPAGE-ENTERTAINMENT-INC/privacy-policy.page.git
cd privacy-policy.page
```

Modify:

- `index.html`
- Accessibility features
- Brand-specific privacy policy dialogs
- Contact information

Commit changes:

```bash
git add .
git commit -m "Update privacy policies"
git push
```

## Deployment

Deployment is performed through GitHub Pages.

After changes are pushed to the configured branch, GitHub Pages automatically publishes updates.
